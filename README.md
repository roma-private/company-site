# スカイラインテクノロジー 企業サイト

スカイラインテクノロジー株式会社（Skyline Technology Inc.）のコーポレートサイトです。
業務システム・モバイルアプリ・クラウド基盤・データ活用を手がけるソフトウェア開発会社として、事業内容や会社情報を紹介します。

## ページ構成

サイトは `index.html` 1ファイルで構成されたシングルページです。

| セクション | 内容 |
| --- | --- |
| ヒーロー | キャッチコピー、運用実績の数値 |
| 事業内容 | 業務システム開発、モバイルアプリ開発、クラウド基盤・DevOps、データ活用・AI 導入 |
| 開発の進め方 | 要件定義から運用までの進め方 |
| 導入実績 | これまでの開発事例 |
| 会社概要 | 会社情報、代表メッセージ |
| 採用情報 | メンバー募集の案内 |
| お問い合わせ | お問い合わせフォーム |

## ファイル構成

```
company-site/
├── index.html   # サイト本体（HTML・CSS・JavaScript を含む）
└── README.md
```

## ブラウザで開く手順

ビルドやサーバーの起動は不要です。`index.html` をブラウザで直接開けば表示できます。

### 方法1: エクスプローラーから開く

1. エクスプローラーで `company-site` フォルダを開きます。
2. `index.html` をダブルクリックします。
3. 既定のブラウザでサイトが表示されます。

別のブラウザで開きたい場合は、`index.html` を右クリックして「プログラムから開く」から使いたいブラウザを選びます。
`index.html` をブラウザのウィンドウにドラッグ＆ドロップして開くこともできます。

### 方法2: コマンドから開く

PowerShell で `company-site` フォルダに移動し、次のコマンドを実行します。

```powershell
start index.html
```

### 補足

- フォントは Google Fonts から読み込んでいます。オフラインの場合は代替フォントで表示されます。
- 変更を反映するには、`index.html` を保存したあとブラウザを再読み込み（F5）します。
